5. One set of flow modes for every river

Each river’s own flow modes are the right description of that river, but they are different shapes at different sites, so their coefficients cannot be compared or pooled. One analysis over every river’s standardized hydrographs gives modes all populations share; the cost is that some rivers are described less well by them, and the second figure says how much.

8. What generalizes, and what does not

Three questions this page is for. They are claims to be argued from the sections above, not read off a single table:

  1. Whether the stage and season are shared. If populations put the effect in the same window of the same life stage, that is a Montana-wide statement with a mechanism behind it – and it tells a water manager which age class a given season’s flow is working on. If they do not, timing is local and each population needs its own curve.
  2. Whether regulated and unregulated rivers differ. Flow can only be managed where it can be moved, so a systematic difference between tailwaters and freestones is the most useful pattern available here. Regulated rivers also vary little in autumn, which is exactly where the flow-mode estimator is weakest (see Methods).
  3. Whether the populations that fail share anything – record length, gage, degree of regulation. A failure explained is more useful than a population quietly dropped.

Every number quoted in the manuscript is in output/tables/derived_stats.csv, regenerated on each run so the text and the figures cannot drift apart.
